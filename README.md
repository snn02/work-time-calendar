# Work Time Calendar

Навык для ИИ-агента: восстанавливает оценку времени по доступной истории чатов, записывает указанную пользователем работу в Google Calendar и готовит отчёты. Поддерживает локальные Codex, Claude Code и OpenCode; в облачном чате доступ зависит от его инструментов и предоставленных данных.

## Что умеет

- По запросу собирает доступные чаты за день или период, определяет проекты и подготавливает краткие записи.
- Понимает ручное описание работы, встречи, осознанного отдыха или простоя и при необходимости уточняет время.
- Сверяет записи с выбранным календарём, добавляет отсутствующие интервалы и сохраняет параллельные проекты отдельными событиями.
- Составляет отчёт по календарю: отдельно сумма по проектам и время без двойного учёта пересечений.

Время между сообщениями — оценка взаимодействия, а не замер непрерывной занятости. Одиночное сообщение без определённой длительности требует уточнения; пауза не считается отдыхом или простоем.

## Требования и подключение

1. Нужен агент, поддерживающий навыки (`SKILL.md`) или способный прочитать его инструкции, и подключённый инструмент Google Calendar с правом читать и создавать события. Возможности разных приложений и тарифов отличаются.
2. Сообщите агенту название или ID целевого календаря и часовой пояс. Он должен проверить доступ к нужному календарю. Одна ссылка на календарь сама по себе не подключает аккаунт.
3. Собственный OAuth-клиент не нужен, если доступен коннектор приложения. Локальные скрипты необязательны для ручного ввода и отчётов.

## Установка для локального агента

Склонируйте репозиторий как каталог навыка в домашнюю папку используемого агента. Примеры для PowerShell:

```powershell
# Codex
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.agents/skills/work-time-calendar"
# Claude Code — альтернативное место установки
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.claude/skills/work-time-calendar"
# OpenCode — альтернативное место установки
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.config/opencode/skills/work-time-calendar"
```

Можно установить в несколько каталогов; обновлять копии потребуется отдельно. Если агент не обнаружил навык, перезапустите его или явно укажите путь к `SKILL.md`. Принятые пути могут зависеть от версии агента.

Для автоматического локального сбора доступных историй нужны Python 3.10+ и локальные данные соответствующих агентов. При использовании другого часового пояса настройте переменную `WORK_TIME_TIMEZONE` с именем IANA. На Windows для базы часовых поясов может понадобиться `python -m pip install tzdata`. Необязательная переменная `WORK_TIME_CALENDAR_ID` добавляет ID в результаты локального помощника; она не подключает календарь.

```powershell
$env:WORK_TIME_TIMEZONE = 'Europe/Moscow'
$env:WORK_TIME_CALENDAR_ID = 'ваш-id-календаря'
python "$HOME/.agents/skills/work-time-calendar/scripts/work_time.py" doctor
```

На Linux/macOS задайте переменные через `export`. Если агент работает и в Windows, и в WSL, истории каждой среды нужно собрать отдельно. Скрипт читает их локально и не отправляет в Google Calendar самостоятельно.

## Облачный чат

В ChatGPT или Claude подключите доступный в вашей среде Google Calendar и добавьте папку навыка способом, поддерживаемым приложением; если такой установки нет, передайте агенту `SKILL.md` и нужные файлы из `references/`. Наличие подключения календаря не предоставляет облаку доступ к историям на компьютере или в другом сервисе. Для общего сбора передайте подготовленный локально экспорт или используйте доступный поисковый инструмент истории. Прямая установка плагина ChatGPT и форматы загрузки зависят от конкретного приложения; этот репозиторий содержит папку навыка, а не готовый плагин.

## Примеры запросов

- «Запиши рабочее время за сегодня по всем доступным чатам и проектам. Сверься с календарём и добавь отсутствующее».
- «Запиши из текущего чата: работал над интеграцией с 10:00 до 11:30. Проект — Альфа».
- «Вчера с 14:00 полтора часа готовил оценку по проекту Альфа».
- «Сегодня в 15:00 сделал осознанный перерыв на 20 минут».
- «С 16:00 до 16:30 устал и не мог работать — запиши простой».
- «Построй отчёт с пятницы по сегодня и предложи улучшения планирования».

Если задана только длительность без начала или конца, агент уточнит недостающее время. Параллельные работы в разных проектах записываются раздельно, но в отчёте личное время объединяется.

Пример события:

```text
Агент: Альфа

Описание: Уточнение требований и проверка интеграции.
Проект: Альфа
Категория: Разработка
Источник: Codex
```

## Приватность и ограничения

Навык не является фоновым трекером и работает при вызове. Исходные истории и личные журналы не входят в репозиторий. Объём доступных чатов ограничен текущей средой и правами; отсутствие данных не означает отсутствия работы. Перед передачей экспорта в облако проверьте его содержимое. Результат отчёта зависит от полноты календаря и данных пользователя.
