# Work Time Calendar

Навык для ИИ-агента: восстанавливает оценку времени по доступной истории чатов, записывает указанную пользователем работу в выбранный Google Calendar или CalDAV-календарь и готовит отчёты. Поддерживает локальные Codex, Claude Code и OpenCode, а в Codex desktop — также доступную облачную историю ChatGPT, включая проекты и архив. Доступ к каждому источнику зависит от инструментов среды и прав аккаунта.

## Что умеет

- По запросу собирает доступные чаты за день или период, определяет проекты и подготавливает краткие записи.
- В общем сборе отдельно проверяет ChatGPT: проходит активную историю и архив по страницам, читает оригинальные сообщения и сообщает о неполном покрытии.
- Понимает ручное описание работы, встречи, осознанного отдыха или простоя и при необходимости уточняет время.
- Сверяет записи с выбранным календарём, добавляет отсутствующие интервалы и сохраняет параллельные проекты отдельными событиями.
- Составляет отчёт по календарю: отдельно сумма по проектам и время без двойного учёта пересечений.

Время между сообщениями — оценка взаимодействия, а не замер непрерывной занятости. Одиночное сообщение без определённой длительности требует уточнения; пауза не считается отдыхом или простоем.

## Требования и подключение

1. Нужен агент, поддерживающий навыки (`SKILL.md`) или способный прочитать его инструкции, и доступный инструмент выбранного календаря с правом читать и создавать события. Возможности разных приложений и тарифов отличаются.
2. Сообщите агенту название или ID целевого календаря и часовой пояс. Он должен проверить доступ к нужному календарю. Одна ссылка на календарь сама по себе не подключает аккаунт. Для CalDAV на Windows можно использовать прилагаемый локальный коннектор.
3. Собственный OAuth-клиент не нужен, если доступен коннектор приложения. Локальные скрипты необязательны для ручного ввода и отчётов.

## Установка для локального агента

Склонируйте репозиторий как каталог навыка в домашнюю папку используемого агента. Примеры для PowerShell 7+:

```powershell
# Codex
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.agents/skills/work-time-calendar"
# Claude Code — альтернативное место установки
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.claude/skills/work-time-calendar"
# OpenCode — альтернативное место установки
git clone https://github.com/snn02/work-time-calendar.git "$HOME/.config/opencode/skills/work-time-calendar"
```

Можно установить в несколько каталогов; обновлять копии потребуется отдельно. Если агент не обнаружил навык, перезапустите его или явно укажите путь к `SKILL.md`. Принятые пути могут зависеть от версии агента.

Для автоматического локального сбора доступных историй нужны Python 3.10+ и локальные данные соответствующих агентов. При использовании другого часового пояса настройте переменную `WORK_TIME_TIMEZONE` с именем IANA. На Windows для базы часовых поясов может понадобиться `python -m pip install tzdata`. Необязательная переменная `WORK_TIME_CALENDAR_ID` добавляет ID в результаты локального помощника; она не подключает календарь.

```powershell
$env:WORK_TIME_TIMEZONE = 'Europe/Moscow'
$env:WORK_TIME_CALENDAR_ID = 'ваш-id-календаря'
python "$HOME/.agents/skills/work-time-calendar/scripts/work_time.py" doctor
```

На Linux/macOS задайте переменные через `export`. Если агент работает и в Windows, и в WSL, истории каждой среды нужно собрать отдельно. Скрипт читает их локально и не отправляет в Google Calendar самостоятельно.

### Сбор ChatGPT из Codex desktop

Если приложению доступны `list_threads` с `source=chatgpt` и `read_thread`, навык добавляет к локальным историям облачные чаты ChatGPT. Он проверяет все страницы активного и архивного списка, учитывает чаты проектов и читает сообщения за нужный период. Если название облачного проекта недоступно, чат всё равно обрабатывается с явным ограничением контекста. Подробности — [references/chatgpt-history.md](references/chatgpt-history.md).

Python-команда `collect` читает только три локальных источника. В её JSON `scope=local_histories`, `complete` относится к локальному набору, а `pending_sources` отмечает ещё не прочитанный ChatGPT. Облачный этап выполняет агент инструментами приложения; наличие этого этапа в Codex desktop не означает его доступность в CLI, Claude Code или OpenCode. Без инструментов/экспорта навык сообщает о недоступном источнике и обрабатывает доступную часть.

Время ответа агента не считается личным рабочим временем. В текущем представлении ChatGPT `startedAt` хода может служить оценочной привязкой единственного запроса, но `completedAt` не определяет конец работы человека. Для одиночного сообщения без заданной длительности навык уточнит время. Повторные страницы, зеркала диалогов и уже учтённые в календаре факты проверяются на дубли.

## Профили и подключение CalDAV на Windows

Подключения хранятся отдельно от навыка в `~/.agents/config/work-time-calendar.json`. Пароль не хранится в этом файле: заранее создайте в Windows Credential Manager запись типа Generic с логином и паролем приложения. Не передавайте пароль в аргументах и не добавляйте его в репозиторий.

В PowerShell из корня скачанного репозитория выполните:

```powershell
# Установить навык для Codex, Claude Code и OpenCode
.\install.ps1
# Установить локальный CalDAV-коннектор и создать профиль (вымышленные примеры)
.\install-caldav.ps1 -ProfileName work -CalDAVUrl 'https://calendar.example.com/dav' -CalendarName 'Рабочий' -CredentialTarget 'work-time-calendar'
```

Установщик создаёт изолированное окружение с зафиксированными зависимостями в `~/.agents/tools/work-time-calendar-caldav`. Нужны PowerShell 7+, Python 3.12, доступ к пакету зависимостей и права на запись в свой профиль. Повторная установка сохраняет существующие профили и не меняет выбранный по умолчанию. URL с логином, паролем, токеном в параметрах или без HTTPS не принимается. После установки попросите агента проверить доступ; способ входа и поддержка сервера зависят от конкретной организации. Текущий коннектор поддерживает сохранённые generic credentials Windows; другие ОС, SSO и OAuth для CalDAV не проверены.

В чате можно сказать:

- «Создай профиль Google `personal` с календарём …».
- «Создай профиль CalDAV `work` для календаря …; запись в Windows Credential Manager называется …».
- «Покажи профили календарей».
- «Удали профиль `work`».

Локальные команды также доступны напрямую:

```powershell
$profileTool = "$HOME/.agents/skills/work-time-calendar/scripts/calendar_profile.py"
python $profileTool --list
python $profileTool --create personal --provider google --calendar-id 'person@example.com'
python $profileTool --create work --provider caldav --url 'https://calendar.example.com/dav' --calendar-name 'Рабочий' --credential-target 'work-time-calendar'
python $profileTool --delete work
# Если удаляется профиль по умолчанию при наличии других:
python $profileTool --delete personal --new-default work
```

`--make-default` при создании выбирает профиль по умолчанию. Создание профиля не подтверждает доступ к календарю; CalDAV-коннектор надо установить отдельно. Удаление удаляет только настройки профиля, не календарь, события или учётные данные. Если после удаления профиля по умолчанию остаются другие, требуется назвать новый профиль по умолчанию. Отсутствующий профиль не заменяется другим автоматически.

## Облачный чат

В ChatGPT или Claude подключите доступный в вашей среде Google Calendar и добавьте папку навыка способом, поддерживаемым приложением; если такой установки нет, передайте агенту `SKILL.md` и нужные файлы из `references/`. Наличие подключения календаря не предоставляет облаку доступ к историям на компьютере или в другом сервисе. Для общего сбора передайте подготовленный локально экспорт или используйте доступный поисковый инструмент истории. Прямая установка плагина ChatGPT и форматы загрузки зависят от конкретного приложения; этот репозиторий содержит папку навыка, а не готовый плагин.

## Цвета событий

Агенты — «Павлин»/бирюзовый, встречи и общение — фиолетовый, ручная работа — оранжевый, отдых — зелёный, простой — серый. Для CalDAV используются близкие стандартные имена цветов; их отображение зависит от клиента и сервера.

## Примеры запросов

- «Запиши рабочее время за сегодня по всем доступным чатам и проектам. Сверься с календарём и добавь отсутствующее».
- «Собери время за 23–24 ноября по локальным агентам и доступным ChatGPT, включая проекты и архив. Покажи покрытие источников и добавь только отсутствующие факты».
- «Запиши из текущего чата: работал над интеграцией с 10:00 до 11:30. Проект — Альфа».
- «Вчера с 14:00 полтора часа готовил оценку по проекту Альфа».
- «Сегодня в 15:00 сделал осознанный перерыв на 20 минут».
- «С 16:00 до 16:30 устал и не мог работать — запиши простой».
- «Построй отчёт с пятницы по сегодня и предложи улучшения планирования».

Если задана только длительность без начала или конца, агент уточнит недостающее время. Параллельные работы в разных проектах записываются раздельно, но в отчёте личное время объединяется.

Пример события:

```text
Агент: Альфа

Описание: Уточнение требований и проверка интеграции.
Проект: Альфа
Категория: Разработка
Источник: Codex
```

## Приватность и ограничения

Навык не является фоновым трекером и работает при вызове. Исходные истории и личные журналы не входят в репозиторий. Объём доступных чатов ограничен текущей средой и правами; отсутствие данных не означает отсутствия работы. Перед передачей экспорта в облако проверьте его содержимое. Результат отчёта зависит от полноты календаря и данных пользователя.
