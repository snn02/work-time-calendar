# Отчёт времени

Прочитай целевой календарь за период полностью, со всеми страницами и экземплярами повторений. Часовой пояс по умолчанию часового пояса пользователя. Отсечь части за границами периода и разбить пересекающие полночь интервалы по дням.

Раздельно покажи сумму длительностей событий по проектам/типам и длительность объединения интервалов. A 10:00–11:00 и B 10:30–11:30: два события, 120 проектных минут, 90 минут занятого периода, 30 минут превышения суммы над объединением. При тройном пересечении превышение не равно длительности календарных участков с любым пересечением; назови показатель точно.

Отметь оценки, события без времени, неклассифицированные события и неполноту покрытия. Пустой календарь не доказывает отсутствие работы. Длина события не доказывает непрерывную концентрацию. Проект, категорию и источник читай из подписанных полей описания, вид активности — из заголовка. Старый служебный блок допустим только как источник миграции. Основание оценки можно знать из исходных материалов, скрытых свойств или доступного приватного журнала; если оно отсутствует, не называй запись измеренным фактом. Ручные события не исправляй ради отчёта.

Анализируй встречи, распределение по времени суток, короткие блоки, смены проектов, позднюю работу и длительные записанные интервалы. Не называй корреляцию причиной и не ставь медицинские/психологические диагнозы.

Если глобальный профиль доступен в этой среде, выборочно используй рабочую роль и согласованные приоритеты. В облаке профиль из ~/.agents/memory сам не появляется: используй предоставленный профиль/память хоста или явно обозначь его отсутствие. Не включай личный профиль в переносимый пакет. Для владельца управленческая работа, пресейл и встречи не считаются потерями по умолчанию. Предлагай 1–3 конкретных изменения расписания с основанием и проверяемым ожидаемым эффектом, без выдуманных целевых долей.

При доступном Python можно передать нормализованные Google events в `python scripts/work_time.py report --from <ISO> --to <ISO> --events <JSON>`. Скрипт считает суммы, а содержательные рекомендации делает агент. Самостоятельный отчёт не создаёт календарных событий.
