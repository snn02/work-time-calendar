# Общий сбор и текущий чат

На начало запуска зафиксируй границу чтения. «Сегодня» — от полуночи часового пояса пользователя до момента вызова; другой день — до следующей полуночи. Ищи сообщения в периоде, включая возобновлённые старые и архивированные сессии.

## Локальные Codex / Claude Code / OpenCode

Общий сбор из любого проекта включает все три источника. Помощник читает Codex `$CODEX_HOME/sessions` и `archived_sessions`, Claude `$CLAUDE_CONFIG_DIR/projects`, OpenCode `$OPENCODE_DATA_DIR/opencode.db`; по умолчанию соответствующие папки пользователя. Чтение SQLite — read-only, с согласованным WAL-снимком. Исходные журналы не меняются.

```text
python scripts/work_time.py collect --date today --output <личный-временный-каталог>/histories.json
python scripts/work_time.py collect --date 2026-11-01 --summary
python scripts/work_time.py collect --from 2026-11-01T00:00:00+03:00 --to 2026-11-01T18:00:00+03:00 --session codex:UUID
```

Команды запускай относительно папки навыка либо абсолютным путём. Истории и подготовленные факты не помещай в общий harness, глобальный навык, ZIP или приватный плагин. Не загружай их в Drive/другой сервис без отдельного указания владельца.

Сначала изучи `coverage`, `errors`, перечень проектов и временные границы; затем только нужные сообщения. `ok` означает успешное чтение этого локального хранилища, а не наличие всех когда-либо существовавших облачных чатов. Нет сообщений Claude за день при успешном чтении — допустимый нулевой результат; недоступная база — неполное покрытие.

Определи смысловые блоки по сообщениям человека и ответам, отмечай оценки. Не считай весь разрыв first–last непрерывной работой. Системные сообщения, сжатие контекста, команды/результаты инструментов, подагенты, автономные проверки и повторённые сообщения после resume/fork не образуют отдельную личную работу. Помощник удаляет явные дубликаты; если версии формата не дают доказать происхождение копий, проверь их по содержанию и временным меткам. Одинаковые слова сами по себе не доказывают дубликат. Не приписывай ожидание агента пользователю без основания.

Для одиночного сообщения без обоснованного конца не добавляй буфер: вынеси интервал на уточнение. Достаточно обоснованные интервалы можно записать по просьбе «запиши» как `chat_estimate`, явно сообщив, что это восстановление по истории. Не проси подтверждать каждый очевидный проект отдельно.

В режиме текущего чата находи нужный source ID и ограничивай выборку им. Если он недоступен, используй явно переданное описание и уточни время; режим самопроизвольно не расширяется на другие чаты.

## Облачные ChatGPT / Claude

Подключённый Google Calendar даёт доступ к календарю, но не к файловой системе компьютера и историям другого сервиса. Используй доступный в хосте поиск собственных чатов/проектов, затем прочитай найденные оригиналы с временем. Не выдавай память или поисковые сниппеты без меток за точный интервал.

Для дня из локальных трёх агентов используй предоставленный экспорт локального сборщика либо явно выбранный владельцем подключённый источник. Не требуй установки сборщика для ручных записей и календарных отчётов. Если общего источника нет, подготовь доступную часть, назови недоступные источники и предложи выполнить `collect` локально и передать экспорт. Не обещай автоматический общий сбор из недоступных чатов.

Для переноса достаточно нормализованных фактов/фрагментов с датами, source IDs, проектом, типом, временем и основанием; передача всех сырых переписок не обязательна. Переносимый формат записи описан в calendar.md.
