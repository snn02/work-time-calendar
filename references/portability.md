# Установка и границы сред

- **Codex / Claude Code / OpenCode на Windows:** общий навык можно установить через `install.ps1`; отдельный CalDAV-коннектор — через `install-caldav.ps1`. Google использует доступное подключённое приложение.
- **Claude cloud / ChatGPT web:** установите навык или совместимый плагин доступным в конкретном продукте способом. Календарный коннектор подключается отдельно. Локальные настройки, истории и Windows Credential Manager не переносятся в облако; для CalDAV нужен доступный облаку коннектор. Доступность зависит от продукта и настроек.
- **Linux / macOS:** инструкции навыка переносимы, но включённый CalDAV-коннектор использует Windows Credential Manager; для других систем необходим совместимый коннектор, который нужно установить отдельно.

Публичный пакет не содержит настройки пользователя или календарный ID. Приватные профили и учётные данные не включаются в ZIP. Подключение в одном хосте не авторизует другие хосты. Для чтения локальных историй из облака нужен доступный источник или явно предоставленный экспорт.
