# Локальный CalDAV-коннектор

Используй, когда личная конфигурация выбрала `provider: caldav`. Прочитай `~/.agents/config/work-time-calendar.json`, проверь имя выбранного профиля, исполняемые файлы `python` и `connector`, календарь и часовой пояс. Выбранное имя календаря задаётся в профиле. Учётные данные берутся коннектором из Windows Credential Manager по указанному в конфигурации имени; не извлекай их в контекст агента, файл, лог или аргументы.

Возьми абсолютные пути `python` и `connector` из выбранного профиля. Установка располагает их вне проекта — в `~/.agents/tools/work-time-calendar-caldav/`. Запусти коннектор с `--profile work inspect` для проверки и с `--profile work list --from <начало-ISO> --to <конец-ISO>` для чтения. Передавай пути отдельными аргументами, учитывая пробелы. Не добавляй секреты в аргументы.

`list` возвращает JSON `items` в формате для `work_time.py reconcile` и `report`, включая скрытые собственные метаданные из CalDAV. Сохраняй результаты только во временный приватный файл, не в проект или общие настройки. Если чтение, раскрытие повторов или распознавание событий не удалось, не создавай события вслепую. Профиль CalDAV однозначно определяет календарь; помощник формирует факты без выбора календаря.

Для явно запрошенного добавления: сформируй и проверь отсутствующие факты обычным `prepare`/`reconcile`, затем передай один подготовленный объект события в приватном UTF-8 JSON как `create --event <путь>`. Коннектор использует стабильный UID и запрет перезаписи существующего объекта, создаёт без гостей и напоминаний и выполняет обратное чтение. Не создавай без предварительной сверки. Если ответ не подтверждён, сначала повторно прочитай календарь по интервалу и UID, не повторяй create наугад. При проверке не удаляй и не редактируй существующие события без явного запроса.

Коннектор преобразует `colorId` в стандартное поле iCalendar `COLOR`: агент — `turquoise`, встреча и общение — `plum`, ручная работа — `sandybrown`, отдых — `limegreen`, простой — `lightgray`, дорога — `gold` (Google `colorId=5`), в том числе при категории «Проекты». Это ближайшие названия цветов, а не идентичные цвета Google. При записи проверяй обратное чтение `color`; отображение зависит от приложения календаря и без визуальной проверки не подтверждено. Облачный ChatGPT/Claude не видит этот локальный коннектор и учётные данные. Подключение облака и межплатформенное хранилище — отдельные задачи; не выдавай локальную работоспособность за облачную.
